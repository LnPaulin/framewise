Framewise

Screen recording, screenshots, text capture and clipboard history for Ubuntu (GNOME).

Install

Download the latest .deb from GitHub Releases, then:

sudo apt install ./framewise_*_all.deb

That also sets up updates: new versions appear in Software Updater.

Update repository

This site hosts the Framewise APT repository at /apt/, signed with the Framewise archive key (fingerprint F69B 9995 8DF3 DE44 9A33 CABF 2B8D 94D1 92EA DC4F). Installing the .deb configures it for you.
